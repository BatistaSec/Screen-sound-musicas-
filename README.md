# 🎵 Screen Sound Músicas

Aplicação em **Java com Spring Boot** para gerenciar artistas e músicas, com persistência em banco de dados e integração com a API do ChatGPT para pesquisa de informações sobre artistas.

---

## 📋 Funcionalidades

- **Cadastrar artistas** (nome + tipo: solo, dupla ou banda)
- **Cadastrar músicas** associadas a um artista já existente
- **Listar músicas** cadastradas no banco de dados
- **Buscar músicas por artista**
- **Pesquisar dados sobre um artista** usando integração com ChatGPT
- Menu interativo no terminal para navegação

---

## 🛠️ Tecnologias Utilizadas

- **Java 17+**
- **Spring Boot 3**
- **Spring Data JPA** (persistência)
- **PostreeSQL** (banco em memória para testes)
- **Maven**
- **OpenAI API** (para pesquisa de artistas)
